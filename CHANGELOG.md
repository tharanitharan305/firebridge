# Changelog

## 0.0.2

- Upgraded dependencies to latest stable versions: `google_sign_in: ^7.2.0`, `flutter_secure_storage: ^11.2.0`, `http: ^1.6.0`.
- Modernized authentication service with Google Sign-In 7.x Credential Manager API and lightweight authentication.
- Resolved pub.dev dependency constraint warnings.

## 0.0.1

- Initial release of `firebridge` Bring-Your-Own-Cloud (BYOC) infrastructure client for Flutter.
- Multiplatform authentication for Android, Web, and iOS.
- Automated 6-step project provisioning engine with propagation delay backoff retries.
- Fluent Cloud Firestore REST client (`CollectionReference`, `DocumentReference`).
- Pre-built Material 3 UI widgets: `FirebridgeProjectPicker` and `FirebridgeErrorDialog`.
- Typed error diagnostics with actionable Google Cloud Console resolution steps.
